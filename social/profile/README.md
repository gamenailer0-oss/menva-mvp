# Instagram profile kit

Images are in `out/`. Regenerate them with `node social/profile/make.mjs`.

| File | Use |
|---|---|
| `profile-picture.png` | Profile photo (1080×1080). The wordmark fits inside Instagram's circle crop. |
| `highlight-how.png`, `-try`, `-restaurants`, `-faq`, `-scans`, `-pilot` | Story highlight covers (1080×1920). Add each one as a story, then choose it as the highlight's cover. |
