# MENVA — Deployment Guide

## Deploy on Netlify

**Option A — connect the Git repo (recommended).** Netlify reads `netlify.toml`, runs `npm run build`, and publishes the `dist/` folder. No settings to type in.

**Option B — drag and drop.** On your computer:

```
npm install
npm run build
```

Then drag the **`dist/`** folder (not the whole project) onto the Netlify dashboard.

Only `dist/` is ever published, so project files such as `CLAUDE.md`, `scripts/` and the raw scans stay private.

## Check a deploy

The model files must be served with the right type, or iPhone AR (Quick Look) will not open:

```
curl -I https://<your-site>/models/gauchos-steak-main.glb    # content-type: model/gltf-binary
curl -I https://<your-site>/models/gauchos-steak-main.usdz   # content-type: model/vnd.usdz+zip
```

## Working locally

```
npm install
npm run vendor   # only after changing a pinned version in package.json
npm run build
npm run serve    # http://localhost:8080 — same headers and routing as netlify.toml
```

## What's where

```
index.html, sw.js               app shell, service worker (robots.txt, sitemap.xml, site.webmanifest and favicon.ico are generated fresh by scripts/build.mjs, not copied)
css/  js/                       styles and app code (no framework, no bundler)
assets/  models/                images and 3D models
vendor/                         self-hosted model-viewer, decoders, fonts (from `npm run vendor`)
scripts/                        tooling: audit, vendor, build, serve
data/                           dishes.csv (source of truth) and model-sources.json
incoming-models/                raw scans — kept on disk, never published, never edited
```

No third-party requests at runtime: model-viewer, its decoders and the fonts are all served from `/vendor`.

## Analytics (Phase 8)

### Netlify Functions
The pilot results page needs two things the drag-and-drop upload can't do:
1. **Deploy from Git or the Netlify CLI** — Netlify Functions (`netlify/functions/`) only deploy that way.
2. **Set `STATS_KEY`** in Netlify → Site configuration → Environment variables (32+ random characters).

Then open `https://<your-site>/stats?key=<STATS_KEY>`. Locally, `npm run serve` runs the same functions in memory; the local key is `local-dev-stats-key`.

## Cloudflare Pages

**Build:** `npm run build`  
**Output directory:** `dist/`  
**Environment variables:** `NODE_VERSION=22` and `SITE_URL=https://<project>.pages.dev` (or your custom domain)  
**Secret:** `STATS_KEY` (32+ random characters)  
**KV namespace binding:** bind `MENVA_EVENTS` to the analytics store in Settings → Functions → KV namespace bindings.

Deploy with Git — Cloudflare Pages Functions (`functions/api/`) auto-deploy. The `dist/_headers` and `dist/_redirects` generated by `npm run build` already configure cache headers and routing for Cloudflare Pages.

## Diner plans: MENVA Plus and MENVA Black (Cloudflare Pages)

Table QR menus (`/g/12`) are always free. Away from a table (`/g`, from home), 3D and AR need a MENVA Plus or Black code, entered at `/unlock`. Payments are manual: once a transfer lands, MENVA makes a code and sends it on WhatsApp.

**One-time setup**
1. Create the code store: `npx wrangler kv namespace create MENVA_CODES`, then uncomment the `MENVA_CODES` block in `wrangler.toml` and paste the id.
2. Add a secret `CODES_ADMIN_KEY` (24+ random characters) in Settings → Variables and secrets.

Until both are done, `/unlock` says "Codes can't be checked right now" and table menus are unaffected.

**Making codes** (from a laptop, with the same key):
```
SITE_URL=https://<your-site> CODES_ADMIN_KEY=… npm run code -- create plus              # 1 month
SITE_URL=https://<your-site> CODES_ADMIN_KEY=… npm run code -- create black --months 3
SITE_URL=https://<your-site> CODES_ADMIN_KEY=… npm run code -- extend 7K3M-Q9TD-2XHV     # renew, same code
SITE_URL=https://<your-site> CODES_ADMIN_KEY=… npm run code -- revoke 7K3M-Q9TD-2XHV
```
It prints the WhatsApp message to send. Codes store only the plan and dates, with no names or phone numbers, so keep the payment ↔ code record in MENVA's own books. Phones re-check a code at most once a day, so a revoke takes effect within a day.

Locally, `npm run serve` runs the same endpoints in memory with the key `local-dev-codes-admin-key`.

**Pitch demos:** a restaurant owner opening `/<slug>` from a link now sees photos only. Send a table link instead (e.g. `/baraza/1`).
